# 镇妖塔 · 设计文档

> 定位：武侠刷宝 × 竖版放置。地上是自家的山门小院（家园），地下是一座倒插地底的镇妖塔——越往下，镇压的妖越老、越凶，宝物也越好。

## 1. 世界观
- 千年前祖师以一座古塔倒镇群妖，塔身没入地底，层层封印。如今封印松动，妖气外泄。
- 主角在塔顶旁的山门小院安家，每次下塔清剿妖物、加固封印，把塔里的宝物、种子、灵宠和被困的江湖人带回地上。
- 地上（家园）= 养成与休整；地下（镇妖塔）= 战斗与收集。两边互相喂养：塔里掉家园资源，家园给战斗加成。

## 4. 镇守大妖
每 10 层一轮，第 2/4/5/7/9/10 层有镇守（同层 5 分钟刷新一次）：血蝠妖、白骨夫人、铜甲尸王、千年树妖、九尾天狐、魔蛟。往下每多一轮加前缀「凶·」「厉·」「魔N·」，数值按周目递增。

## 5. 武学触发器
烈焰掌（每 N 次普攻）、惊雷诀（暴击连锁）、漫天花雨（定时全体）、金钟罩（低血护盾）。等级来自技能树，后续以「顿悟」解锁变招。

## 6. 掉落
- 装备：普通 / 魔法（蓝）/ 稀有（黄）/ 暗金，带保底；拾取过滤低于设定品质自动卖出。
- 家园资源：种子、装饰、灵宠、伙伴（精英与镇守身边更容易救出被困伙伴）。
