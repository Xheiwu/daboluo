# 镇妖塔 · 设计文档

> 定位：武侠刷宝 × 竖版放置。地上是自家的山门小院（家园），地下是一座倒插地底的镇妖塔——越往下，镇压的妖越老、越凶，宝物也越好。

## 1. 世界观
- 千年前祖师以一座古塔倒镇群妖，塔身没入地底，层层封印。如今封印松动，妖气外泄。
- 主角在塔顶旁的山门小院安家，每次下塔清剿妖物、加固封印，把塔里的宝物、种子、灵宠和被困的江湖人带回地上。
- 地上（家园）= 养成与休整；地下（镇妖塔）= 战斗与收集。两边互相喂养：塔里掉家园资源，家园给战斗加成。

## 4. 镇守大妖
每 10 层一轮，第 2/4/5/7/9/10 层有镇守（同层 5 分钟刷新一次）：血蝠妖、白骨夫人、铜甲尸王、千年树妖、九尾天狐、魔蛟。往下每多一轮加前缀「凶·」「厉·」「魔N·」，数值按周目递增。

## 4.5 每层地图（已实现）
- 每层随机生成 22×29 格地图：3×4 间石室（随机去掉 1–3 间）用生成树走廊连通，再加少量回环；入口在最上排，下行阶梯在最下排离入口最远的石室。
- 内容：普通怪群（每间 1–2 群）、精英怪群（1–2 群，引妖香翻倍）、死胡同秘藏（70%）、镇守殿（镇守层的阶梯石室）。
- 主角自动寻路：最近的怪群/秘藏优先，清空后走阶梯；路过怪群 2 格内会被缠上。
- 停留本层时，走阶梯 = 妖气重聚，刷新同层新地图。

## 4.6 材料·炼制·悬赏（已实现）
- 妖物材料：山魈→兽骨、跳尸→尸蜡、纸人→符纸、毒蛛→蛛丝、狐妖→狐毛、游魂→魂晶、鬼火→磷火、机关铜人→精铜、蛇妖→蛇胆。
- 场景材料（精英 / 秘藏 / 镇守）：古墓玉、寒铁、火精、幽冥石；镇守材料：血蝠翼、白骨簪、尸王甲片、千年树心、狐火珠、蛟鳞。
- 每层固定一种主妖（权重 ×4），塔志可按材料查楼层并前往。
- 丹符（限时 30 分钟）：镇妖符（伤害 +25%）、回春丹（疗伤药 +2、减伤 5%）、引妖香（精英怪群 ×2）、寻宝罗盘（掉宝 +60%、材料 +50%）。
- 法器（永久，10 级）：镇妖铃（伤害）、护心镜（减伤）、聚宝葫芦（材料/掉宝）；高等级需要更深场景材料与后段镇守材料，用来卡进度。
- 悬赏：镇压某妖 / 收集材料 / 击杀精英 / 讨伐镇守，目标层不超过最深层。

## 5. 武学触发器
烈焰掌（每 N 次普攻）、惊雷诀（暴击连锁）、漫天花雨（定时全体）、金钟罩（低血护盾）。等级来自技能树，后续以「顿悟」解锁变招。

## 6. 掉落
- 装备：普通 / 魔法（蓝）/ 稀有（黄）/ 暗金，带保底；拾取过滤低于设定品质自动卖出。
- 家园资源：种子、装饰、灵宠、伙伴（精英与镇守身边更容易救出被困伙伴）。
