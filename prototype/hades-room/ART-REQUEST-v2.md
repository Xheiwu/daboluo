# 素材需求 v2（交给 GPT 生成）

v1 的做法很好用，v2 沿用同一套规矩：**透明 PNG + 横排/网格 + 统一锚点 + README + atlas-metadata.json**。
生成后放到 `assets/art-reference/hades-pack-v2/`（新建分支 `art/hades-pack-v2`，或推到 `art/hades-pack-20261023` 都行）。

## 通用规则（每张都要满足）
1. **风格与 v1 完全一致**：暗黑哥特武侠，Hades 式手绘，粗墨线，硬阴影，青绿石面，血红与古金点缀，青色幽火。
2. **镜头**：固定 3/4 斜俯视（与 v1 地砖同一个等距角度），光从左上来。
3. **透明背景**，不要地面、不要投影、不要文字/标注/水印。
4. **同一角色必须是同一个人**：生成主角时把 `hades-pack-v1/hero-poses.png` 当参考图；跳尸同理参考 `jiangshi-poses.png`。服装、发色、配色、比例不能变。
5. **同一张图内统一缩放**：主角站立身高 ≈ 600px（与 v1 idle 一致），跳尸 ≈ 690px。不要每格各自放大缩小。
6. **每格之间留 ≥40px 透明间隔**，武器、披风、火焰不能被格子裁掉。
7. 所有角色**面朝右**（左边由代码镜像）。特别注明的“背面”除外。
8. 每张图附 metadata：文件名、尺寸、格子大小、行列、每格内容、地面锚点（脚底中心）坐标。

## P0 · 战斗手感（最优先）

### 1. `hero-combo.png` — 主角三连击
- 尺寸 5400×724，横排 6 格，每格 900×724，地面锚点 (450,680)。
- 顺序：
  1. 横斩·蓄势：身体右转蓄力，剑收在左腰后，剑尖朝后。
  2. 横斩·挥出：剑水平横扫到右前方，手臂伸直，披风与红带被甩开。
  3. 突刺·蓄势：压低重心，剑收到右肩旁，剑尖朝前。
  4. 突刺·伸展：大弓步前冲，剑完全水平前伸，后腿蹬直。
  5. 跃起·举剑：双手举剑过头，人在空中（脚底比锚点高约 120px，锚点不变）。
  6. 下劈·落地：半蹲落地，剑劈到身前地面，剑尖触地。
