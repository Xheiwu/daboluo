# 镇妖塔 · 一房间试制（hades-pack-v1）

只验证实际战斗手感：**一个房间、一个主角、一种跳尸**。不接入现有游戏代码。

- 打开：`prototype/hades-room/index.html`（需本地静态服务器，例如 `python3 -m http.server`，素材读取 `../../assets/art-reference/hades-pack-v1/`）。
- 操作：只用摇杆移动（触屏任意空白处按下即出现浮动摇杆；桌面可用 WASD / 方向键）。普攻三连与三个技能全部自动。
- 右上「自动攻击」可点按开关，方便对比站桩与走位。
- `?auto` 自动走位演示；`?capture` 为录屏用的逐帧模式（`window.__step()` / `window.__frame()`）。

## 素材用法
- 角色按 atlas-metadata 的锚点对齐，每个角色统一缩放；姿势是独立关键帧，不连播冒充动画。
- 节奏全部由代码补：前摇后仰 → 出刀姿势 + 前冲 → 命中停顿(hitstop) + 闪白 + 击退 + 震屏 → 收招；跑动用起伏/倾斜/尘土。
- 跳尸：直腿蹦跳靠位移+落地压缩；攻击前红圈预警，跃起用 `jump_attack`（离地高度由代码给，不单独缩放）；受击用 `hit_recoil`；死亡化墨灰、符纸飘落、掉金币/魂晶。
- 地砖按 alpha bbox 逐块裁切，统一 104×52 菱形，放大 7% 叠压掩盖接缝；装饰按 bbox 裁切并分别设地面锚点，旗面用逐列切片做摆动。
- 命中范围、伤害、受击判定与图像边缘无关，全部为代码数值。

## 普攻三连（自动）
① 横扫：扁平宽弧，近身扇形　② 突进斩：前冲一大步 + 直线刀芒 + 残影　③ 跃起大劈：起跳举剑 → 竖劈 + 落地震波、镜头冲击。
当前只有 v1 的四个姿势，三连靠位移/缩放/旋转与姿势交叉淡化区分；`hero-combo.png` 到位后替换为真实关键帧（见 ART-REQUEST-v2.md）。

## 跳尸攻击与预警
- 扑杀（中距）：身体泛红 + 头顶「！」+ 轨迹箭头 + 落点圈逐渐填满，满圈闪白后起跳，0.62s 预警。
- 抓挠（近身）：扇形红区填满后横抓，0.42s 预警。
