# 镇妖塔 · 地牢一层试制（hades-pack-v1）

可玩的一整层：**随机房间 + 走廊 → 进房封门刷波次 → 精英 / 小首领 / 首领 → 掉落 → 下一层或回小院**。不接入现有游戏代码。

- 打开：`prototype/hades-room/index.html`（需本地静态服务器，例如在仓库根目录 `python3 -m http.server`）。
- 操作：只用摇杆移动（触屏空白处按下出现浮动摇杆；桌面 WASD / 方向键）。普攻三连与三个技能全部自动；右上「自动攻击」可开关。
- 调试参数：`?auto` 自动驾驶（会寻路、躲红圈、找冲击波缺口）；`?start=elite` 直接到尸将堂；`?start=boss` 直接到首领；`?seed=数字` 换地图；`?exit=down` 自动驾驶打完首领后走楼梯；`?capture` 录屏逐帧模式。

## 一层的结构
- 9 个房间（每深一层 +1，最多 12），最小生成树 + 2 条回环，3 格宽走廊。墙体为临时代码绘制（等 `walls_iso` 素材），主角被墙挡住时墙体半透明。
- 迷雾：走过的地方才显示；小地图右上角，标出首领（首）、宝箱（金点）、未清精英房（紫点）。
- 房间类型：入口 / 尸房（2 波）/ 血衣尸卫（精英 + 2 词缀）/ 尸将堂（小首领 + 3 词缀）/ 藏宝阁（宝箱）/ 旱魃殿（首领，离入口最远）。
- 进入房间：门口落下红色「封」字符墙，清完所有波次才解开。
- 首领死后出现两个出口：右「下一层 ▼」（怪物血量/伤害随层数提高）、左「回小院」（显示本次战果面板，家园用途的材料会单独标出）。
- 试玩不会死亡：血量归零触发「回魂」（满血、震退周围怪），结算面板记录回魂次数。

## 精英词缀（随机组合）
狂暴（更快、冷却短）· 坚甲（减伤 50%、几乎不被击退）· 震地（扑杀范围 ×1.5 + 落地放三缺口冲击波）· 尸毒（脚下周期留毒池）· 闪现（紫圈预警后闪到你身边接抓挠）· 唤尸（周期召小尸）· 分裂（死后裂成两只小尸）· 尸爆（死后大范围红圈爆炸）· 护体（护盾，破盾有特效）。
精英头顶显示名字（如【狂暴·震地】血衣尸卫）、血条、护盾条，脚下有词缀颜色光环。

## 小首领 · 尸将（额外招式）
- **十字血爪**：以你为准的 4 道长条裂地，0.6 秒后再来错开 45° 的 4 道 —— 必须换位两次。
- **连环震地**：连续 3 圈只有两个缺口的冲击波，每圈缺口方向随机。

## 首领 · 尸王旱魃（3400 血，两阶段）
| 招式 | 范围 | 躲法 |
|---|---|---|
| 三连震地跳 | 每跳预判你的走位，落点 100 半径红圈 | 红圈满前离开；二阶段 4 连跳，落点留毒池 |
| 巨爪横扫 | 半径 210 的巨型扇形 | 绕到身后或拉开 |
| 缺口冲击波 | 扩散到 560，2～3 圈 | 跟着绿色虚线站进缺口 |
| 血符雨 | 10 个（二阶段 16 个）符纸落点，第一张正对你 | 连续横移 |
| 血爪裂地（二阶段） | 6 道 420 长的放射裂地，两轮错开半角 | 站在两道之间，第二轮再换 |
| 唤尸 | 召小尸，二阶段带一只狂暴精英 | 优先清小怪 |
半血进入「暴怒」：全屏红闪 + 召援军，所有招式冷却 ×0.65、冲击波缺口变窄、连招接冲击波；光照变红。

## 掉落
- 品质：凡 / 良 / 珍 / 绝 / 传说（颜色区分；珍以上有光柱、拾取闪光）。普通尸少量掉，精英必掉 2 件装备，尸将 3 件，首领必出 1 件传说 + 尸王獠牙。
- 装备自动穿戴每个部位最高战力的那件，战力直接提升伤害；左上显示战力。
- 家园材料：灵兽蛋（宠物）、奇花种子（种田）、古宅图纸（装饰）、尸王獠牙（锻造）—— 结算面板单列，下一步接小院系统。

## 主角（沿用 v2）
普攻三连：横扫 / 突进斩 / 跃起大劈。技能：幽冥掌 4.5s、金轮斩 7s、血影斩 9s（压暗 + 一闪）。突进类位移会被墙挡住。

素材需求见 [ART-REQUEST-v2.md](ART-REQUEST-v2.md)（墙体 `walls_iso`、精英/首领独立形象到位后可直接替换当前的染色缩放跳尸）。
