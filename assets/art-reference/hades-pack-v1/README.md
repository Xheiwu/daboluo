# 暗黑武侠试制素材包 v1

用途：给 Opus 制作一房间、一主角、一跳尸的画面验证。只控制方向移动，自动攻击；先验证跑动、砍怪和技能，不要一次铺完整游戏。

## 文件
- hero-poses.png：3600×724，横排四格，每格900×724。顺序为待机、跑步姿势、向下挥剑、掌心聚气。每格地面锚点(450,680)。
- jiangshi-poses.png：2700×800，横排三格，每格900×800。顺序为待机、跃起攻击、受击。共同地面锚点(450,750)。攻击姿势刻意离地，不要逐帧贴底或单独缩放。
- ground_tiles_4x4.png：1774×887，四行四列。各行依次青石、裂纹、金边、血迹。透明背景。需要逐块裁切并统一世界尺寸、菱形边界。尚未做引擎拼接测试，不能认为已经无缝。
- decorations_7_padded.png：1774×887，上排幽火火盆、石柱、破旗、墓碑；下排石像、红枫、锁链、空位。请按对象 alpha bbox 裁切并分别设置地面锚点，不要盲目按二等分高度切图。上下物件交界约 y=470。
- atlas-metadata.json：尺寸、顺序、锚点及限制。坐标以图像左上角为原点，单位像素。

## 动画与实现边界
这批是 AI 生成的静态素材及独立关键姿势，不是连续动画序列，更不是完整八方向动作。左右镜像只能用于试制，不能补出真实前后朝向。四个主角姿势不能直接连播冒充流畅挥砍；先用短位移、停顿、受击闪白、刀光和独立粒子验证节奏，后续再补同一动作的连续帧或骨骼动画。火焰、旗帜等也没有自带动画。

攻击范围、命中时刻、受击判定和伤害由代码单独实现，不要按图像可见边缘推断碰撞。将刀光等特效与人物分层，保留地面锚点。相机固定斜俯视3/4，避免正面立绘直接贴上战场。

本包只交付试制素材，尚未在游戏中实测接缝、缩放可读性、动作衔接或触控体验。不修改现有游戏代码。先做短实机片段验证，再决定是否扩展其他怪物和场景。
